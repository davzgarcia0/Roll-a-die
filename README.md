# 🎲 Roll-a-Die - RPG Dice Roller

Um aplicativo mobile de rolagem de dados para RPG de mesa, projetado para oferecer uma experiência imersiva que combina uma interface medieval 2D responsiva com uma sala de física 3D para a rolagem real dos dados. 

## ✨ Funcionalidades

* **Rolagem Rápida (Sistemas D20):** Interface dedicada para testes rápidos com opções de Vantagem (VAN), Desvantagem (DES) e ajuste de Classe de Dificuldade (CD).
* **Rolagem Livre (Free Roll):** Sistema de equações personalizadas que permite aos jogadores montar paradas de dados complexas (ex: `3d6 + 2d4 + 5`).
* **Sala de Dados 3D:** Transição fluida da interface para um ambiente 3D onde os dados são rolados utilizando o motor de física nativo.
* **Histórico de Rolagens (Last Rolls):** Registro de texto (com formatação em tempo real) mantendo o histórico de todos os ataques e testes da sessão.
* **Design Responsivo:** UI baseada em containers que se adapta perfeitamente a qualquer resolução de celular, suportando dinamicamente os modos Retrato e Paisagem.

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Motor Gráfico/Programação:** [Godot Engine](https://godotengine.org/) (GDScript)
* **Modelagem 3D:** Blender (Criação dos modelos poliédricos dos dados)
* **Edição de Imagem/UI:** Adobe Suite (Criação e texturização da interface estilo pedra/pergaminho)
* **Controle de Versão:** Git & GitHub
